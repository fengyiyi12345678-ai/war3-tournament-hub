# 🪟 Windows 一键操作指南（不用碰命令行）

## 🎯 全部流程：3 个步骤，10 分钟搞定

---

## 第 1 步：装 Python（如果已经装过就跳过）

1. 打开微软商店（Microsoft Store）
2. 搜 **`Python 3.12`** → 点 **「获取 / Get」** 安装
3. 等待安装完成（约 1 分钟）

> 💡 也可以去 https://www.python.org/downloads/ 下载安装包
> ⚠️ 用安装包的话**一定要勾上 `Add Python to PATH`**

---

## 第 2 步：下载本项目

1. 浏览器打开：
   ```
   https://github.com/fengyiyi12345678-ai/war3-tournament-hub/tree/claude/search-football-matches-STVPM
   ```

2. 右上角绿色按钮 **`<> Code`** → **`Download ZIP`**

3. 下载完后**右键解压**

4. 进入解压后的 `war3-tournament-hub-claude-search-football-matches-STVPM\video-pipeline\` 文件夹

---

## 第 3 步：双击运行

找到这个文件：

### 📁 `双击运行.bat`

**对着它双击** ✅

会弹出一个黑色窗口，自动做 4 件事：
```
[1/4] 检查 Python              ← 几秒
[2/4] 检查 ffmpeg              ← 第一次会下载 100MB，约 2 分钟
[3/4] 安装 yt-dlp              ← 几秒
[4/4] 下载素材 + 渲染视频      ← 约 5–7 分钟
```

**全程不需要你输入任何东西**，只要等。

---

## 🎉 完成后

- 黑窗口最后一行会说 **「🎉 全部完成」**
- 文件管理器会**自动弹出** `out\` 文件夹
- 里面就是 `lazio_inter_30s.mp4`

把这个 mp4：
1. **微信传到手机**（电脑微信 → 文件传输助手）
2. 手机上**抖音 → 发布 → 选这个视频**
3. 复制以下文案 ↓

```
🔥 国米已经拿冠军了，凭啥还要赢这场？
拉齐奥憋了 26 年的大招要来了！

#意大利杯决赛 #拉齐奥 #国际米兰 #足球分析
#今晚看球 #足球预测
```

## 🎵 想加 BGM？（可选）

1. 把任意 mp3 文件**重命名为 `bgm.mp3`**
2. 把它丢到 `video-pipeline\` 文件夹里
3. 重新双击 `双击运行.bat`

抖音曲库下载步骤：
- 抖音 APP → 找一个用了你喜欢 BGM 的视频
- 点右下角音符 → 「保存到本地」
- 把音频文件传到电脑，改名 `bgm.mp3`

或者去免费音乐站：
- https://pixabay.com/music/search/sports/ （搜 sports）
- https://www.bensound.com/

## ❓常见问题

### Q1: 双击后窗口闪一下就关了
👉 你的电脑没装 Python。**回到第 1 步装 Python**。

### Q2: 提示「下载失败」
👉 网络问题。检查：
- 能不能打开 YouTube（这个项目素材在 YouTube 上）
- 公司网络可能挡了，**用家里 / 手机热点**重试

### Q3: 视频里中文是方块 / 显示不出来
👉 Windows 自带的微软雅黑应该会被自动检测到。如果还不行，**截图发给我**。

### Q4: 想改文案 / 改时长
👉 改 `make_video.py` 里的 `TIMELINE` 列表，每行格式：
```python
(序号, 时长秒, 类型, 素材key, 起始秒, "标题", "副标题", "颜色/滤镜")
```

### Q5: 想换比赛 / 换素材
👉 改 `make_video.py` 里的 `YT_SOURCES` 字典，把 YouTube 链接换掉。
