# Seedance 提示词撰写规范

> Seedance 1.0 Pro / Lite 是字节跳动的视频生成模型，推荐使用「主体 + 场景 + 动作 + 镜头 + 风格」五段式中文 prompt，长度 30–100 字效果最佳。

## 一、五段式结构

```
[主体描述] + [所在场景] + [主体的动作 / 状态] + [镜头语言] + [风格 / 氛围]
```

例：

> 一瓶透明玻璃香水瓶，瓶身刻有金色花纹，悬浮在云雾缭绕的深蓝色背景中，瓶身缓缓旋转、雾气从瓶口溢出，镜头缓慢推进至瓶身中央，高级电影感，冷色调，柔光，4K。

## 二、镜头语言（运镜）词表

| 中文 | 英文 | 适用 |
| --- | --- | --- |
| 推镜头 | push-in / dolly in | 强调主体、聚焦细节 |
| 拉镜头 | pull-out / dolly out | 收尾、展示环境 |
| 环绕镜头 | orbit / arc shot | 360° 展示产品 |
| 跟随镜头 | follow shot | 跟拍人物 / 移动物体 |
| 摇镜头 | pan | 横向揭示场景 |
| 升降镜头 | crane up / down | 鸟瞰 / 抬升 |
| 微距推进 | macro push | 细节材质特写 |
| 静帧 | locked-off | 字幕位、卖点强调 |
| 手持跟拍 | handheld follow | 真实感、生活场景 |

## 三、风格锚 / 氛围词

- **电商高级**：电影感、冷色调、高对比、柔光、广告片质感、Vogue 风
- **生活场景**：温暖光线、暖黄调、家居自然光、纪录片感
- **科技感**：赛博朋克、霓虹色、深空背景、悬浮粒子、未来主义
- **国风**：水墨、留白、青绿山水、古风器物
- **新中式**：原木质感、暖白光、低饱和、极简构图

## 四、参数推荐

| 参数 | 推荐值 | 说明 |
| --- | --- | --- |
| 时长 | 2–5 秒 | Seedance 单段上限 ~10s，但电商短镜头 2-5s 最佳 |
| 比例 | `16:9` / `9:16` / `1:1` | 抖音横屏 16:9，竖版用 9:16 |
| 帧率 | 24 / 30 | 电影感选 24，生活感选 30 |
| 运动强度 | low / medium / high | 产品展示用 medium；动作演示用 high |

## 五、负向提示词模板

```
低质量, 模糊, 抖动, 水印, 文字错位, 多余手指, 畸变, 闪烁, 帧间跳变
```

## 六、产品锚定的工程技巧

为了让 9 段视频里的产品**长得一样**，建议：

1. 每条 Seedance prompt 的主体描述部分**完全复用**同一段产品描述（来自 Agent 1 的 `product_meta`）
2. 主体描述长度控制在 15–25 字，太短会被模型创作发挥，太长会挤压镜头语言空间
3. 如果 Seedance 支持参考图（i2v），优先用 Agent 1 拼图里的对应 cell 作为参考图

## 七、合规约束

- 不要出现明确的真实品牌名、明星名、版权图案
- 不要描述未成年人 + 产品（如「12 岁小孩使用化妆品」会被拒绝）
- 医美 / 药品 / 烟酒 类产品避免「疗效」「治愈」等承诺词
