# 示例输入

## 场景
某新锐香水品牌想推一款琥珀色玻璃瓶香水的抖音短片。

## 输入数据

```json
{
  "image_url": "https://example.com/product/amber-perfume-white-bg.png",
  "style_anchor": "高端电影感, 冷色调, Vogue 杂志风, 柔光, 4K",
  "language": "zh"
}
```

> `image_url` 应该是一张干净白底的产品图（推荐 1024×1024 或更大）。

见 [`example-output.json`](example-output.json)。
