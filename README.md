# 足球分析中心 · Football Analysis Hub

一个零依赖的静态网站，覆盖主要联赛的对阵、赔率与赛程。

## 功能

- **对阵 & 赔率**：英超 / 西甲 / 德甲 / 意甲 / 法甲 / 欧冠主流联赛比赛卡片，1X2 赔率展示
- **赛程**：按日期分组展示未来比赛
- **积分榜**：可切换联赛查看积分排名（自动按胜场/净胜球排序）
- **赛事详情**：点击对阵卡片可查看场地、近期战绩 (W/D/L) 与赔率隐含概率
- **筛选 & 排序**：按联赛、日期筛选；按时间或主胜赔率排序

## 运行

直接用浏览器打开 `index.html` 即可，无需构建工具或服务器。

```bash
# 可选：用任意静态服务器
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 文件结构

- `index.html` — 页面骨架与导航
- `styles.css` — 暗色主题与响应式布局
- `data.js`   — 联赛 / 球队 / 比赛 / 赔率 / 积分榜数据
- `app.js`    — 渲染、筛选、模态框逻辑

数据为示例数据，仅供分析展示参考。
